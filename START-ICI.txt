BY CARS — VERSION V4 : MOBILE & DISPONIBILITÉ PROCHAINEMENT

IMPORTANT : si votre base Supabase existe déjà, commencez par l'étape 1.

1. BASE SUPABASE EXISTANTE
   Supabase > SQL Editor : exécutez :
   supabase/migration-disponibilite-prochainement.sql
   Vos véhicules existants ne sont ni supprimés ni remplacés.

   NOUVELLE BASE : exécutez supabase/schema.sql, puis créez votre
   compte utilisateur dans Authentication > Users et autorisez-le
   avec supabase/add-admin.sql. Le seed.sql est facultatif et n'est
   PAS à lancer sur un stock commercial existant.

2. GITHUB PAGES
   Décompressez ce ZIP. Envoyez son CONTENU à la racine de votre dépôt.
   CONSERVEZ VOTRE config.js EXISTANT si vous avez déjà connecté Supabase !
   Faites Commit changes et attendez que le workflow GitHub Pages termine.
   Ce site est statique : aucun npm ni build nécessaire.

3. ADMINISTRATION
   https://www.by-cars.fr/admin.html
   Ajouter / Modifier un véhicule > Publication > Disponibilité du véhicule
   Valeurs : Disponible / Disponible prochainement / Indisponible.
   Cochez « Publié » pour que l'annonce soit visible aux visiteurs.

4. DESIGN
   Cartes et filtres du catalogue mieux adaptés aux téléphones.
   Mention « société automobile » sur le site à la place de l'ancienne formulation.

Voir README.md pour les détails. Ne communiquez pas de clé secrète Supabase.
