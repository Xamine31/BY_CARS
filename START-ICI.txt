BY CARS — NOUVELLE VERSION

1. Si Supabase est déjà configuré : exécutez supabase/migration-site-settings.sql dans Supabase > SQL Editor.
2. Si Supabase est neuf : exécutez supabase/schema.sql puis créez votre utilisateur Auth et donnez-lui accès avec supabase/add-admin.sql.
3. Dans config.js, mettez votre URL Supabase et votre clé publishable.
4. Envoyez le CONTENU du dossier sur GitHub et faites Commit changes.
5. Sur GitHub : Settings > Pages > GitHub Actions.
6. Accès admin : https://VOTRE-COMPTE.github.io/VOTRE-DEPOT/admin.html
7. Depuis l'admin : Coordonnées & personnalisation pour les réseaux, adresses, numéros et image d'accueil.

Pour les détails, consultez README.md.
