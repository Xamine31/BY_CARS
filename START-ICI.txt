BY CARS — MISE EN LIGNE

1) Supabase > SQL Editor : exécuter supabase/schema.sql
2) Optionnel : exécuter supabase/seed.sql pour préremplir le stock
3) Supabase > Authentication > Users : créer votre compte e-mail + mot de passe
4) Modifier supabase/add-admin.sql avec votre e-mail puis l'exécuter
5) Supabase > Connect / Settings > API Keys : copier Project URL + Publishable key
6) Mettre ces 2 valeurs dans config.js
7) Envoyer tout le dossier sur GitHub
8) GitHub > Settings > Pages > Source : GitHub Actions
9) Faire un commit sur main
10) Admin : https://VOTRE-COMPTE.github.io/VOTRE-DEPOT/admin.html

Ne jamais mettre de clé Supabase secret/service_role dans le site.
