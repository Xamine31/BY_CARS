BY CARS — VERSION MODERNE MAGHREB / GITHUB SANS BUILD
======================================================

MISE EN LIGNE
1. Décompresse le ZIP.
2. Remplace les anciens fichiers de ton dépôt GitHub par TOUT le contenu du ZIP.
3. Vérifie que .github/workflows/deploy.yml est présent.
4. Fais Commit changes.
5. GitHub > Settings > Pages > Source : GitHub Actions.
6. Attends que Actions passe en vert.

PAGES
- index.html : accueil
- stock.html : catalogue + barre de recherche + filtres
- vehicule.html?id=ID : fiche dédiée de chaque voiture
- export.html : export vers l’Algérie, le Maroc et la Tunisie
- contact.html : contact
- admin.html : administration (aucun bouton admin visible sur le site)

ADMIN SANS BASE
Tu peux déjà ouvrir admin.html même sans Supabase.
Le site passe en MODE DEMO LOCAL : tu peux ajouter/modifier des véhicules et les voir sur le site dans le même navigateur.

Quand Supabase sera connecté dans config.js, l'admin utilisera automatiquement la connexion sécurisée Supabase.

IMPORTANT
Aucun npm, aucun Vite, aucun build. GitHub Pages publie directement les fichiers.
