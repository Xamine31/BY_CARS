BY CARS — VERSION MULTIPAGE MODERNE
===================================

1. Décompresse le ZIP.
2. Dans ton dépôt GitHub, remplace les anciens fichiers par TOUT le contenu du ZIP.
3. Vérifie que .github/workflows/deploy.yml est bien présent.
4. Fais Commit changes.
5. GitHub > Settings > Pages > Source : GitHub Actions.
6. Attends que l'onglet Actions passe en vert.

PAGES :
- index.html = accueil
- stock.html = recherche et catalogue
- vehicule.html?id=ID = une fiche dédiée par voiture
- export.html = export Algérie
- contact.html = contact
- admin.html = administration privée (aucun bouton admin sur le site public)

SUPABASE :
- configure config.js avec ton URL Supabase + clé publique anon/publishable
- exécute supabase/schema.sql dans SQL Editor

IMPORTANT :
Cette version n'utilise ni npm, ni Vite, ni build. Elle est faite pour GitHub Pages directement.
