BY CARS — DESIGN MODERNE + MOBILE — PRÊT POUR GITHUB PAGES

MISE À JOUR DU DÉPÔT
1. Décompresse ce ZIP.
2. Dans ton dépôt GitHub, remplace les anciens fichiers par TOUT le contenu de ce dossier.
3. Vérifie que .github/workflows/deploy.yml est présent.
4. Fais un Commit sur la branche main.
5. GitHub > Actions : attends que "Deploy to GitHub Pages" soit vert.

ADMINISTRATION
Aucun bouton Administration n'est visible sur le site public.
Accès direct uniquement par l'URL :
https://TON-COMPTE.github.io/TON-DEPOT/#/admin

L'espace admin reste protégé par Supabase Auth + la table admins.
Le fait de cacher le lien n'est pas utilisé comme sécurité : l'authentification Supabase reste obligatoire.

SUPABASE
Le site fonctionne en mode démo sans Supabase.
Pour le vrai stock, ajoute dans GitHub > Settings > Secrets and variables > Actions :
- VITE_SUPABASE_URL
- VITE_SUPABASE_ANON_KEY

Ne mets jamais la clé service_role dans GitHub Pages.

MOBILE
Le design est responsive : menu mobile, cartes adaptées, filtres empilés,
galerie tactile par glissement et barre Appeler / WhatsApp sur les fiches véhicule.
